ClipHarbor - Download. Edit. Export.

1. Open ClipHarbor from the desktop or Start menu.
2. On first launch, stay online while the setup window downloads media tools.
   Your browser then opens automatically. Keep that tab for downloading and editing.
3. Use Save project to keep edits for another day.
4. When finished, click Quit app in the top right. Closing the browser tab alone
   leaves the app running so a download or export can finish.

No Python, Conda, Node.js, terminal commands or separate FFmpeg installation needed.
Internet is needed for first-time setup and downloading online media.
After setup, editing local files works offline.

The editor has Media at the left, the full video preview in the center, Properties
at the right, and the timeline across the bottom. Drag the three dividers to
resize. The folder icon shows/hides Media (yellow means open). Properties follows
the file, timeline section, or layer you select. The video is never cropped to
fill the preview. Fullscreen is separate; press Escape to return to editing.

To save a download to Google Drive, select Google Drive under Output and click
Sign in with Google. Export uses that same remembered connection and folder.
ClipHarbor never asks for your Google password. Account permissions are protected
by your operating-system account. Disconnect removes the local connection and
attempts to revoke Google's permission.

For a personal Facebook profile, choose Facebook in Export, then Personal profile.
ClipHarbor prepares the MP4 and opens Facebook in your browser. Click Copy video
location, choose Photo/video in Facebook, and paste into its file picker. Choose
your audience and finish posting in Facebook. Copy post text copies your caption.
No Facebook password or access token is saved in ClipHarbor for this option.
The completion screen means the video is ready; it does not mean it was posted.
For a Page you manage, choose Page I manage and switch to your Page in Facebook
before attaching the file. Advanced Page API uploads remain available separately.

Export also offers YouTube, X and direct Facebook Page uploads. YouTube needs
separate upload permission and defaults to private. X and Facebook Page uploads
require the platform access tokens explained in the app and online README.
Facebook personal-profile sharing has been tested with a successful Only me post.
X and direct Facebook Page API uploads still require real-account validation.
The YouTube upload test is waiting for the test account's temporary restriction
to end; Google sign-in and upload authorization were verified.
Direct-to-Drive downloads use temporary local space, then remove the temporary
files after a verified upload. Failed uploads can be retried from Activity.

Projects and cache are stored in %LOCALAPPDATA%\ClipHarbor.
Downloaded/exported files go to the output folder you choose.
Saved projects refer to source files: do not move or delete those files.
Uninstalling or installing a newer version does not remove projects or media.

Updates: quit the app, then run the newer ClipHarbor installer from the person who
shared it with you. This build does not download or install updates automatically.

This is an unsigned Windows 10/11 x64 build. Windows may display an unknown-
publisher warning. Only install the file if you trust the person who sent it;
do not disable Windows security. It is not a macOS or Linux installer.

If startup fails, details are in %LOCALAPPDATA%\ClipHarbor\logs\clipharbor.log.
