Post an exported video through Facebook

This optional companion operates the normal Facebook website in your own signed-in browser. It attaches the MP4, inserts your caption, selects your requested audience, and clicks Post. The app reports success only when it observes Facebook’s confirmation. This is experimental browser automation, not a Meta publishing API.

One-time setup

  1. Install ClipHarbor 0.9.0 or newer.
  2. Open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select the installed facebook-extension folder. Normally: %LOCALAPPDATA%\Programs\ClipHarbor\facebook-extension. This is separate from the downloader extension.
  3. Review the stronger browser permission. This companion needs the debugger API to attach a local video without loading the entire file into extension memory. Chrome does not support requesting that permission optionally. The companion’s code attaches only to Facebook tabs it creates, but Chrome’s debugger permission itself is powerful and is not technically restricted to one website. Install this optional component only if you accept that access.
  4. Open your own Facebook profile. If asked, sign in yourself. Pin ClipHarbor Post, click it, and choose Connect this Facebook profile. Your profile must show Edit profile. No password or cookie is copied to ClipHarbor.
  5. In ClipHarbor Export, choose Facebook → My profile · post through browser companion, enter your caption, choose the audience, and click Post video to Facebook or Render & post to Facebook.

What to expect

Keep the connected browser open. The companion checks for requested exports about every 30 seconds. It opens a dedicated Facebook tab and shows Chrome’s debugging banner while preparing the post. The local video is kept. The requested audience defaults to Only me, and the companion leaves your Facebook default-audience setting unchanged.

A different existing draft or attachment stops the task. Finish or discard that draft yourself in Facebook before starting another export. Sign-in, security checks, unsupported languages, changed controls, unavailable audiences, or a browser interruption can also stop it. The English desktop interface is the primary validation target; other interface variants may need updates. It does not solve CAPTCHAs, bypass account restrictions, or fill authentication dialogs.

Never assume a timed-out publication failed. Once the Post click was attempted, a lost confirmation is an uncertain result. ClipHarbor tells you to check your profile and does not automatically submit again. Manual Facebook preparation and the advanced official Page API option remain available in Export.

Privacy and local data

The optional companion receives only an explicitly exported file location, caption, chosen audience, and connected profile. The file is attached through Chrome’s local-file input support, not encoded into large messages or copied into extension memory. It uses the Facebook session managed by your browser; no Facebook password, cookie, or Google token enters ClipHarbor’s companion protocol.

The extension keeps a random browser identifier, connected profile name, enabled state and status message in local browser storage. ClipHarbor remembers that browser ID and profile URL/name in its local data. Pending post captions and file locations are held by the running app. They are not analytics and are never sent to a ClipHarbor cloud server. Stop browser posting from the extension popup to stop polling. Removing this companion does not remove the downloader or your videos.

Only the browser most recently connected in this app receives posting tasks. Switching to another browser while a task is active is blocked. Direct Facebook Page publishing is a different official API flow and does not need this companion.
