ClipHarbor browser companion

Download a video from the page you are watching, using ClipHarbor on this computer.

One-time setup

  1. Install ClipHarbor 0.9.0 or newer. Open it once and finish the media-tool setup.
  2. Open Chrome’s Extensions page (chrome://extensions) or Edge’s Extensions page (edge://extensions).
  3. Turn on Developer mode, choose Load unpacked, and select the installed browser-extension folder. On Windows it is normally %LOCALAPPDATA%\Programs\ClipHarbor\browser-extension. You can also extract the extension ZIP from the release and select that folder.
  4. Pin ClipHarbor to your browser toolbar. On a video page, click its folder/harbor icon and choose your format and destination.

This release is distributed from GitHub. It is not listed in the Chrome or Edge stores. Browser installation is a one-time manual step; ClipHarbor does not force-install extensions or change browser security policies.

Downloading

The popup uses the current page and, where available, visible video links. If a page has several videos, choose the intended one or paste its individual permalink. You can also right-click a video, link, or page and choose Download with ClipHarbor; this uses the format and destination from your last successful extension request.

MP4 is the default. Downloads continue after the popup closes. The toolbar badge shows running downloads; reopen the popup for progress and completed files. Open app shows Activity, including extension downloads. Quit ClipHarbor from its app when finished.

Google Drive

Choose Google Drive in the popup. If needed, click Connect in ClipHarbor and finish Google’s sign-in. The extension uses the same protected connection and folder as Download and Export. After connecting, reopen the popup. Temporary media is removed only after Drive verifies the upload; failed uploads can be retried from ClipHarbor’s Activity.

Privacy and permissions

The extension reads the active page and visible media links when you invoke it. It has no access to your stored passwords or browser cookies, requests no access to every website, and sends no analytics. Native messaging talks only to the locally installed ClipHarbor bridge. Google credentials and the desktop session secret stay in the app.

Browser storage keeps recent download identifiers, progress and output locations. It keeps no general browsing history. Remove the extension to remove its browser storage. ClipHarbor’s separate folder/format preferences and downloaded files remain on your computer.

Some websites require authentication or prohibit downloading, and protected media may not be supported. This companion uses ClipHarbor’s existing supported sources; it does not bypass DRM or guarantee every website. Cookies are never copied automatically from your browser.

Source users

Install the source dependencies, then run python browser-extension/register_host.py from the repository using your ClipHarbor Python environment. Keep that environment and checkout in place. Load browser-extension as described above. Run the same script with --unregister to remove that source bridge. Windows installer registration and source registration share the same host name, so the most recent setup wins.
